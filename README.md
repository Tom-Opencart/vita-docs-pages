# Вита — документация шаблона (GitHub Pages)

Публичное руководство пользователя по шаблону **Вита** для OpenCart 3.x.
Сайт собирается из репозитория темы (`docs/`) и разворачивается здесь автоматически.

**Адрес:** https://tom-opencart.github.io/vita-docs-pages/

## Состав (только публикационные файлы)

- `index.html` — одностраничное руководство (58 групп, поиск, тёмная тема)
- `assets/vita-docs.css` / `assets/vita-docs.js` — оформление и логика
- `assets/search-index.js` / `assets/search-index.json` — поисковый индекс (275 записей)
- `.github/workflows/deploy.yml` — деплой на Pages при пуше в `main`

## Источник правды

Файлы **не редактируются здесь вручную**. Источник — папка `docs/` репозитория темы;
после правок там они копируются сюда для публикации. Генераторы индексов,
AI-база (`ai-knowledge.json`), гейты и рабочие артефакты остаются в репозитории темы.
